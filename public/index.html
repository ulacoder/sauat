Как работает

Ошибка — это начало подсказки, а не конец задания

Тексты в формате PISA: объявления, расписания, научно-популярные статьи, два мнения. Каждое предложение кликабельно.

Читает

Текст из жизни: расписание сельского автобуса, сайгаки, Арал, телефоны в школе.

Отвечает

Выбор варианта, свой ответ или «нажми предложение-доказательство».

Ошибся — лестница

Стратегия → нужный абзац → нужное предложение. Ответ не выдаётся сразу.

Растёт

Модель IRT пересчитывает уровень трёх навыков и подбирает следующий текст.

Для сельской школы

Интернет нужен один раз — чтобы открыть ссылку

Приложение весом около 150 КБ сохраняется на телефоне. Ответы копятся в очереди и уходят учителю, как только появится сеть. Нет сети совсем — ученик показывает QR-код, учитель сканирует камерой.

Учитель

Видит уровень по 3 навыкам, трудные вопросы и советы ИИ на следующий урок.

Учителю

Кабинет, который отвечает на вопрос «что делать на следующем уроке?»

📊

Аналитика по PISA

Уровень класса и каждого ученика по навыкам «найти», «понять», «оценить», динамика по неделям, вопросы, где класс ошибается.

✨

ИИ-студия

Новый текст по любой теме или задания из текста учебника — 4 вопроса PISA с подсказками и доказательствами за минуту.

🧠

ИИ-сводка недели

Три конкретные рекомендации с именами учеников. Есть запасной режим по правилам, если ИИ недоступен.

📌

Задания со сроком

Выдайте текст классу и смотрите, кто выполнил. Задания скачиваются на телефоны и работают офлайн.

🔗

Вход по коду

Ученик вводит 6-значный код класса и имя. Никаких email и паролей у детей.

🖨

Отчёт

Печать для педсовета и экспорт в CSV одной кнопкой.
