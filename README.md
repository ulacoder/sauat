# Sauat — учим не просто читать, а понимать

**Órleu Hack 2026 · Кейс 3 «Образование: читать и понимать» · команда tech-jacket**

Sauat («сауат» — грамотность) — ИИ-тренажёр функциональной грамотности (чтение, формат PISA) для 7–9 классов, который работает в сельской школе без интернета, и кабинет учителя с аналитикой по трём навыкам PISA.

- **Сайт:** https://sauat.vercel.app
- **Приложение ученика:** https://sauat.vercel.app/app/ (класс для пробы: код `DEMO24`)
- **Демо-кабинет учителя:** https://sauat.vercel.app/teacher/?demo

## Что умеет

**Ученик (PWA, офлайн)**
- Тексты в формате PISA на казахском и русском: объявление/расписание, научно-популярный текст, два мнения, информационный текст.
- Три навыка PISA: найти информацию, понять и сделать вывод, оценить и обдумать.
- Тип задания «нажми предложение-доказательство» — тренирует опору на текст.
- Лестница подсказок: стратегия → абзац → предложение; ответ не выдаётся сразу.
- Адаптивность: модель Elo/1PL IRT оценивает уровень каждого навыка и подбирает следующий текст под самый слабый.
- Офлайн: service worker кеширует приложение (~150 КБ); ответы копятся в очереди и синхронизируются, когда появится сеть. Без сети совсем — QR-код результата для учителя.
- ИИ-коуч проверяет открытые ответы онлайн; офлайн — рубрика по ключевым мыслям на двух языках.
- Вход по 6-значному коду класса, без email и паролей. XP и серия дней.

**Учитель**
- Обзор: KPI, средний уровень класса по 3 навыкам, доля ниже базового уровня, динамика по неделям, вопросы, где класс ошибается чаще всего, предупреждения.
- Ученики: уровень каждого по навыкам, карточка ученика с ответами (включая открытые).
- Задания со сроком и прогрессом выполнения.
- Библиотека и **ИИ-студия**: новый текст по теме или задания из текста учебника — 4 вопроса PISA с подсказками; сервер проверяет, что каждое доказательство — реальное предложение текста.
- **ИИ-сводка недели**: 3 рекомендации по данным класса (запасной режим без ИИ).
- Приглашение по коду/QR, отчёт для печати и CSV.

## Стек

- Фронтенд: HTML/CSS/JavaScript без фреймворков и сборки (работает на слабых телефонах), PWA + Service Worker.
- Бэкенд: одна serverless-функция Node.js на Vercel (`api/index.js`).
- База: PostgreSQL (Neon). Локально — встроенная PGlite, ничего ставить не нужно.
- ИИ: Gemini 2.5 Flash через Vercel AI Gateway (OIDC-токен проекта, ключи не хранятся в коде).
- Библиотека QR: qrcode-generator (MIT).

## Как запустить

```bash
git clone https://github.com/ulacoder/sauat
cd sauat
npm install
npm run dev        # http://localhost:3000
```

Без `DATABASE_URL` используется PGlite в памяти, демо-класс `DEMO24` создаётся автоматически. Для ИИ локально задайте `AI_GATEWAY_API_KEY` (см. `.env.example`); без него работают офлайн-проверка и запасные рекомендации.

## Структура

```
public/            статика: лендинг, /app (ученик, PWA), /teacher (кабинет), js/content.js (тексты)
api/index.js       API: класс, вход ученика, синхронизация, задания, аналитика, ИИ
lib/db.js          Postgres (Neon) / PGlite, схема
lib/stats.js       аналитика класса (Elo/IRT, динамика, трудные вопросы)
lib/seed.js        демо-класс
lib/ai.js, coach.js, generate.js   ИИ-коуч и генератор заданий
scripts/dev.js     локальный сервер
```
